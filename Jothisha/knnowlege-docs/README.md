# Sri Lankan Astrology (Jothisha) — Knowledge Base

A reference collection on Sri Lankan (Sinhala) astrology — locally known as **Jothisha** or **Hela Jothisha** — covering its history, core concepts, practical methodology, cultural role, and professional ethics. Written as a factual, educational reference: it documents the tradition and how it is practiced, without asserting or denying the validity of astrological claims. Yogas, doshas, and predictive methods are described as traditional interpretive frameworks, not verified facts.

Each file lists the sources consulted during research at its end.

## Scope and caveats

- This is a general reference on the tradition as commonly documented, not a substitute for consulting a qualified practitioner, nor a personal horoscope reading.
- Sri Lankan practice shares its computational framework (Grahas, Rashis, Nakshatras, Dasa systems) with Indian Vedic Jyotish, but has distinct regional terminology, chart conventions, and cultural integration — this is noted throughout rather than treated as identical.
- Terminology and category counts (e.g. porondam categories, named yogas) vary between astrologers and sources; where research found disagreement, the files note it rather than presenting one version as definitive.
